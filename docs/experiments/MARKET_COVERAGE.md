## Восстановление WhiteBIT Spot

9 ноября 2026 года на локальном тестовом WebSocket проверены закрытие соединения, HTTP 503 при первой попытке переподключения и успешная повторная подписка. В промежуточном цикле WhiteBIT Spot имел статус `partial`. Bid/Ask были пустыми, цена последней сделки оставалась доступной. Первое обновление после переподключения было принято с новым, меньшим идентификатором.

В отдельной живой проверке закрыто собственное соединение с публичным WebSocket WhiteBIT. Кэш очистился. Новое соединение получило Bid/Ask BTC/USDT через 274 мс от запуска повторной подписки. Этот замер исключает ожидание до очередного цикла сбора. В изолированном Playwright карточка WhiteBIT Spot → Bybit убрала просроченные Bid/Ask и входной спред во время HTTP 503 от локального API. Свежий снимок вернул значения при автоматическом опросе без перезагрузки.

9 ноября в сохранившемся отрезке 12:38:10–12:48:19 по Киеву опубликовано 42 снимка WhiteBIT Spot со статусом `ok`. В каждом были свежие Bid/Ask для 320–333 из 341 рынка, медиана — 328. Максимальный наблюдаемый возраст — 59,952 с. Журнал зафиксировал подключение WebSocket и остановился без события отключения, поэтому причину окончания процесса из него установить нельзя.

Возобновлённый отрезок 16:17:12–17:41:42 по Киеву дал 339 полных снимков со статусом `ok` для WhiteBIT Spot. Свежие Bid/Ask были доступны на 323–339 из 341 рынка, медиана — 336. Котировок старше 60 секунд среди опубликованных не было. Максимальный интервал между снимками — 22,923 с.

Контроль полноты допускает 10 секунд вокруг одного часа и по-прежнему отклоняет пропущенные часы. ## Ограничения замера

- OKX отдаёт текущий фандинг по выбранному инструменту. У MEXC в массовом тикере есть ставка, а интервал и время приходят по запросу инструмента. У HTX следующий момент доступен в массовом ответе. Интервал в карточке может быть восстановлен, если три последних события дают регулярный шаг и опубликованный следующий момент совпадает с этим шагом. [OKX API](https://www.okx.com/docs-v5/en/#public-data-rest-api-get-funding-rate) · [MEXC Contract API](https://mexcdevelop.github.io/apidocs/contract_v1_en/#get-contract-funding-rate) · [HTX Linear Swap API](https://huobiapi.github.io/docs/usdt_swap/v1/en/)
- В первоначальном REST-снимке WhiteBIT Spot не вернул Bid/Ask. Запрос отдельного стакана BTC/USDT ответил. Покрытие сетевых статусов и OI остаётся выборочным.
- Числа отражают публичные ответы в проверенном окне. Устойчивость на длинном прогоне и полный паритет с UAInvest предстоит проверить.
