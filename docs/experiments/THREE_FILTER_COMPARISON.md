# Сверка UAInvest по трём фильтрам

## Условия и привязки

Капитализация от 1 млн USD, Crypto, USDT. Режим «Лонг + шорт · спред», группировка по монете и сортировка по Open Spread по убыванию на 12 общих площадках. Порог оборота локально пуст. В интерфейсе UAInvest выставили `Обсяг = 0`, потому что пустой параметр в адресе страницы приводит к запросу с порогом 1 млн. Прямые ответы API без параметра и с `volume=0` на одной метке дали по 50 групп, из которых 38 имели оборот ниже 1 млн хотя бы на одной ноге. При `volume=1` было 35 групп. [Проверка порога оборота](../evidence/three-filter-volume-2026-11-11.json)

Добавлен 31 нативный контракт для UP, BEAM, BULLA, RSR, CYBER, Q и GRAM. Реестр вырос с 70 до 76 активов. UP на OKX, Aster, Gate и MEXC привязан к Unitas. OKX прямо называет Unitas в анонсе, а каталог Aster указывает тег `Unitas`. Superform с тикером UP имеет другой CoinGecko ID. Для игрового BEAM CoinGecko указывает WhiteBIT и Bybit с тикером BEAM и Binance с тикером BEAMX. На Binance сохранён нативный идентификатор `BEAMXUSDT`. [Привязки и размеры](../evidence/three-filter-registry-2026-11-11.json) · [Анонс OKX](https://www.okx.com/en-eu/help/okx-to-list-perpetual-futures-for-up-crypto) · [Unitas](https://www.coingecko.com/en/coins/unitas) · [Superform](https://www.coingecko.com/en/coins/superform) · [Рынки Beam](https://www.coingecko.com/en/coins/beam-2)

## Результат Playwright

11 ноября в 12:11:25 по Киеву метки публикации отличались на 124 мс. Все 31 новые привязки использованы живым API. Опубликованы оценки для 76 активов, ответили 21 из 21 источников. В 37 из 50 публичных строк оборот хотя бы одной ноги был ниже 1 млн.

GOOGL исключён из сравнения по признакам TradFi. У BP, GRAM и DRV нога EdgeX подтверждена в локальном каталоге как USDC. После этих проверок сравнивались 46 строк из опубликованного топ-50. Нижняя часть публичного списка этим снимком не охвачена.

До группировки локальные фильтры прошли 8 точных публичных направлений. У них медиана абсолютной разницы Open Spread составила 0.047 п.п. В паре UP OKX → Aster биржевые метки локальных ног расходились на 126 мс. Локальный Ask 0,1375 и Bid 0,1393 дали 1,30058%, публичный список показал 1,22877%. Капитализация Unitas составила 29,69 млн USD в CoinGecko и 19,75 млн USD в публичной строке со статусом `ambiguous`. Публичный список не указывает отдельные метки Bid/Ask и идентификатор использованного актива. [Снимок Playwright](../evidence/three-filter-snapshot-2026-11-11.json)

## Критерии качества

В этом замере локальный скринер отсеял подтверждённые ошибки охвата и подтвердил идентичность обеих ног для новых строк. Публичная выдача остаётся шире. Для оценки качества поиска нужны доля подтверждённых связок среди лидеров, доля найденных допустимых связок и свежесть исполнимых Ask/Bid. Стабильность этих показателей в длинном прогоне пока не проверена.
