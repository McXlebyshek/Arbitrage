# Сверка funding Paper Trading — 2026-11-05

Версия 0.23. Добавлены read-only чтение архива исторических ставок и ручная
CLI-сверка funding для открытых/закрытых paper-позиций. Прогнозные ставки не
начисляются. Settlement mark prices задаются отдельным файлом; их происхождение
автоматически не проверяется. Это расчёт симуляции, не история счёта.

13 новых тестов `tests/test_paper_funding.py`:

- Собственные интервалы двух ног, знаки LONG/SHORT, отрицательные ставки при правке.
- Вход исключён, точное время закрытия включено; подтверждённое отсутствие выплаты даёт ноль.
- Недостающие mark prices дают только отдельную оценку по входному номиналу, итог null.
- Внутренний пропуск, отсутствующий хвост и левый контекст не считаются покрытием.
- Ошибочный/отстающий импорт и неверный asset сбрасывают прежний полный итог.
- Повтор/перезапуск не удваивают начисление; исправленная ставка пересчитывается с аудитом.
- Неверные/конфликтующие цены, нечисловые значения, времена и будущие наблюдения.
- Нормализация mark price для price_units=1000 и частичный набор цен.
- Отсутствующая/старая база, отсутствие создания файла, read-only архив, разные базы.
- Атомарный откат при ошибке записи события.
- Новая переоценка сбрасывает funding; повтор той же mark-команды сохраняет его.
- Лимит событий не превращает усечённую историю в полную.
