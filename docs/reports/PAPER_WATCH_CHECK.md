# Закрепление и автопереоценка Paper Trading — 2026-11-05

Версия 0.24. Монитор читает live paper-журнал и закрепляет REST-сбор ног
первых 10 открытых позиций. Новый отдельный watcher переоценивает их по свежему
latest.json; автоматических входов/закрытий нет. UI не изменялся.

12 новых тестов `tests/test_paper_watch.py` проверили:

- Read-only чтение и отсутствие создания отсутствующего ledger; replay/старый формат/закрытые исключены.
- Отключённую биржу, изменение реестра, лимит 10 и явное число пропущенных позиций.
- Идемпотентную автопереоценку и перезапуск без нового marked для того же снимка.
- Проверку свежести даже повторного снимка; остановленный источник и отсутствие глубины.
- Ошибки JSON/источника/SQLite, сохранение последней оценки, отсутствие новых позиций.
- Защиту путей статуса от перезаписи входов/постороннего JSON.
- Сохранение двух inputs при пустом scanner и отсутствие новых economics.rows.
- Снятие закрепления после закрытия, funding-selection вне WS-поднабора.
- Временную ошибку чтения: удержание в grace и снятие через 10с.
- Работу engine только с закреплениями, остановку и отмену задач сбора.

Полный набор: **214 Python-тестов и 11 проверок JS прошли**.

`validate_paper_watch.py` использовал искусственные данные с текущими временами,
отдельный тестовый реестр, live-mode ledger и заглушённый сбор без внешних запросов.
Он выполнил реальные CLI-проходы watcher и проверил:

| Параметр | Результат |
|---|---|
| Кандидатов scanner / economics.rows | 0 / 0 |
| Сохранено ног в inputs | 2 |
| Первый проход | marked |
| Повторный проход | already_current |
| Остановленный источник | blocked |
| Событий marked после всех проходов | 1 |
| Открытых позиций после проверки | 1, без автоматического закрытия |

Метрики: [PAPER_WATCH_METRICS.json](PAPER_WATCH_METRICS.json).
Это не рыночный сигнал или результат реального счёта. Длительная живая проверка
API/ресурсов при закреплённых позициях, загрузка settlement mark prices,
автосверка funding, UI и полная статистика пока не выполнены.
Этап 11 остаётся частичным. Ограничения: [PAPER_WATCH.md](../PAPER_WATCH.md).
