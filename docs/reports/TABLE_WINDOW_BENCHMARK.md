# Виртуализация длинной таблицы

Пункт 27. При выдаче более 160 строк таблица оставляет в DOM видимое окно,
запас до и после окна и строку, в которой находится клавиатурный фокус.
Остальную высоту сохраняют отступы. Обновления при прокрутке объединяются
в кадр, подготовленная выдача переиспользуется до смены фильтров или данных.

Синтетический стенд с 1 000 монетами сравнил `4c97b30` и `4256281`
в одном Chrome. 21 измерение после пяти прогревов.

| Сценарий | До | После |
| --- | ---: | ---: |
| Строки в DOM при лимите 800 и прокрутке сверху | 800 | 24 |
| Обновление выдачи из 800 строк, p50 / p95 | 77,5 / 87,5 мс | 4,4 / 4,6 мс |
| Обновление обычных 80 строк, p50 / p95 | 9,7 / 11,0 мс | 9,7 / 11,3 мс |

Измерено синхронное обновление DOM. Playwright проверил прокрутку на
100 строк, логический индекс, сохранение фокуса, поиск и мобильную ширину.
