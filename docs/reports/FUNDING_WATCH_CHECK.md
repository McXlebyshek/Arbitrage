# Фоновая сверка funding — 2026-11-05

Версия 0.27. Добавлены отдельный worker и постоянный Binance-кэш в paper-журнале.
Основные базы и позиции пользователя в проверках не использовались.

9 новых тестов проверили:

- Офлайн-сверку и повтор без нового события начисления.
- Кольцевую очередь закрытых, первые 10 открытых/omitted, replay/отсутствующий файл.
- Ошибку ручного файла без изменений; отсутствующий архив без нулевой подстановки.
- Общий бюджет трёх запросов на пять обрабатываемых позиций.
- Паузу 429 для всех последующих позиций и повторного экземпляра worker.
- Ошибку одной позиции с продолжением остальных.
- Реальную запись/чтение JSON checkpoint при повторном запуске run().
- Принятую Binance-цену в постоянном кэше после mark, удалившей старый funding:
  следующая сверка использовала кэш с нулём HTTP-запросов.
- Атомарный откат строки кэша и результата при ошибке вставки события.

Существующий тест адаптера расширен на Retry-After и HTTP 418.
Полный набор: **243 Python-теста и 11 проверок JS прошли**.

`validate_funding_watch.py` выполнил реальные одноразовые CLI-запуски worker на
отдельной искусственной позиции/истории/ценах. Только контролируемый fixture был
переведён в live-формат, чтобы проверить live-only очередь; это не настоящий
рыночный paper-эпизод. Результаты:

| Проверка | Результат |
|---|---|
| Первый цикл / повтор | ready / ready |
| Сетевых запросов | 0, сеть выключена |
| Добавленных дубликатов аудита | 0 |
| После удаления файла цен | rates_covered_marks_missing |
| Итоговый net без цен | null |

Машинный отчёт: [FUNDING_WATCH_METRICS.json](FUNDING_WATCH_METRICS.json).
Другие точные settlement-адаптеры не добавлялись. Проверенные публичные схемы
истории [Gate](https://www.gate.com/docs/developers/apiv4/en/futures/),
[Bitget](https://www.bitget.com/docs/catalog/market/derivatives) и
[MEXC](https://mexcdevelop.github.io/apidocs/contract_v1_en/#get-contract-funding-rate-history)
содержат ставки/времена, без поля цены конкретного начисления. Свечи/текущая цена
не подставляются. Это не исключает существования иных подходящих источников.

Живой длительный совместный прогон и расширенная статистика остаются в плане.
UI не менялся, этап 11 остаётся частичным. [Инструкция](../FUNDING_WATCH.md).
