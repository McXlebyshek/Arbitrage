# Проверка ядра Paper Trading — 2026-11-05

Версия 0.22. Проверена первая ручная CLI-симуляция. Реальных позиций, ордеров,
положительных рыночных сигналов или заявленной рыночной доходности этот отчёт не содержит.

14 новых тестов `tests/test_paper.py` проверяют равное количество, бюджет и комиссии,
закрытие по многослойному VWAP, неизменность количества при смене расчётного бюджета,
повторы команд/эпизодов, replay/live, свежесть относительно текущих часов,
недостаток глубины, разрыв времени/будущие времена, смену параметров контракта,
запрет времени назад, поздние стаканы закрытия, общий резерв, восстановление после
перезапуска, освобождение бюджета и атомарный откат при ошибке записи события.
Проверены read-only status, отсутствие создания файла при просмотре и защита рыночной БД.

Воспроизводимый `validate_paper_cycle.py` выполнил реальные CLI-команды open → close →
status на явно искусственных снимках и отдельном временном реестре:

Артефакт: [PAPER_CORE_METRICS.json](PAPER_CORE_METRICS.json).
Полный набор: 189 Python-тестов и 11 проверок JS. Исходные данные и журнал тестового
цикла находятся в отдельной `data/paper-core-check`; они не подменяют latest.json
или основную рыночную базу. UI и сборщик в этой версии не изменялись.

Funding, удержание сбора открытых ног, автопереоценка, UI и живая paper-проверка
ещё не выполнены. Этап 11 остаётся частичным. Ограничения: [PAPER.md](../PAPER.md).
