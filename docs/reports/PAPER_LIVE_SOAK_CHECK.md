## Найденный сбой и исправление

Первый запуск завершился неуспешно через 108,28с: watcher переоценки остановился
с `[WinError 5]` при замене `mark-status.json`, пока файл читался другим процессом.
Первичные метрики сохранены в [PAPER_LIVE_FIRST_FAILURE_METRICS.json](PAPER_LIVE_FIRST_FAILURE_METRICS.json).
HTTP-ошибок до аварии не было, но это не делает запуск успешным.

Общая запись JSON теперь использует уникальный временный файл в том же каталоге
и атомарную замену с максимум 8 попытками при `PermissionError` (суммарные паузы
0,71с). Предыдущий целый JSON остаётся доступным до успешной замены. Другие ошибки
и постоянный запрет записи не скрываются; собственный временный файл очищается
по возможности. Это не гарантия сохранности при отключении питания.
Исправление применяется к снимкам, отчётам, статусам paper и файлам обслуживания.

Шесть новых тестов проверяют кратковременную/постоянную блокировку, прочие ошибки,
NaN, коллизию имени и настоящий открытый Windows reader-handle с освобождением
блокировки из другого потока. Полная проверка: 257 Python-тестов, 11 JS-проверок.

## Ограничения результата

Совместная работа прошла проверки (`orchestration_passed=true`), но качество данных
неполное: монитор закончил с кодом 1, `market_data_quality=data_gaps_at_stop`.
Binance переподключался 6 раз (WS closed 1006), средняя доля свежих котировок
после прогрева — 73,64%; Gate — 63,14%. Bybit/OKX/Bitget/MEXC — 100% в проверенных
выборках после прогрева. Выборки раз в 2с не доказывают непрерывную доступность.
У MEXC отмечено 10 синхронизаций стаканов; metadata failures не было.

**Confirmed не было, paper-позиций 0.** Оба paper-worker оставались idle;
paper SQLite не создавалась, проверка её целостности и конкурентной записи
в этом запуске отсутствует. Положительный живой цикл вход → funding → закрытие,
восстановление открытой позиции и суточная устойчивость остаются непроверенными.
Сетевой сбор settlement mark prices в этом запуске не включался.

Изменённые процессы получают исправление JSON после перезапуска. Результат
не подтверждает полную готовность MVP или расчёт фактической доходности.
