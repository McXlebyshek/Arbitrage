## Поставка и ограничения

В 0.37 стандарт монитора Binance — depth5@500ms, группа 20. Другие источники,
включая прежний bookTicker, остаются доступны по --binance-stream. Настройки
бирж раздельны: новый --binance-group-size дополнительно ограничен --group-size.
Стенд публичной проверки передаёт этот параметр явно, конфигурация записана в report.
Старое сравнение validate_stream_groups.py закреплено за bookTicker, чтобы смена
стандарта не меняла смысл воспроизведения исторической проверки.

Предыдущий прогон 0.36 дал только 52,46% свежих Binance. Он не отменяется новым
успешным окном. Точная причина разницы между сессиями не установлена; десять
минут не подтверждают сутки, полное покрытие истории или реальное исполнение.

Проверены передача/ограничение размера группы в реальном lifecycle пула, отказ
CLI от неверного размера и новый стандарт на локальном combined WebSocket.
Четыре теста анализа окон покрывают прогрев/границы, loading/reconnecting,
пустую ёмкость, частичную последнюю минуту и чтение без создания исходной базы.
Регрессия: 305 Python-тестов / 11 JS-проверок.
