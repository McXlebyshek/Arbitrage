# Совместный контролируемый paper-прогон — 2026-11-05

`validate_paper_joint.py` запускал независимые асинхронные задачи публикации
искусственного снимка, переоценки, сверки funding и чтения, используя отдельные
SQLite-соединения/потоки. Это проверка взаимодействия ядер, **не отдельные реальные
демоны и не живая биржевая сессия**.

Данные полностью искусственные, модельное время ускорено на 12 часов. Ledger,
архив и цены созданы в отдельной папке `data/paper-joint-check`. Сетевых запросов,
торговых операций и изменения пользовательских позиций не было.

| Измерение | Результат |
|---|---|
| Реальное время | 30.17с |
| Искусственных публикаций | 60 |
| Проверок переоценки | 548 |
| Сверок funding | 280 |
| Согласованных чтений | 570 |
| Ошибок | 0 |
| SQLite integrity_check | ok |
| Ожидаемый / полученный funding | 1.537584 USDT |
| Ожидаемый / полученный итог | 9.438096 USDT |

Чтение сверяло, что известный net принадлежит тому же временному окну, что
переоценка/funding, и равен результату до funding плюс funding. Перезапись суммы
между оценками допускается, двойное накопление не допускается. В конце виртуальная
позиция закрыта по последнему искусственному стакану и сверена независимо по
четырём заданным событиям и четырём комиссиям. Открытых позиций осталось 0,
закрытых 1. Числа не являются рыночной доходностью проекта.

Метрики: [PAPER_JOINT_METRICS.json](PAPER_JOINT_METRICS.json).
Повтор с новой папкой:

```powershell
.\.venv\Scripts\python.exe validate_paper_joint.py --duration 30 --output data/paper-joint-check-2
```

Проверка не заменяет длительный живой прогон, межпроцессные сбои/перезапуски,
лимиты API, суточную устойчивость и проверку полного MVP (пункты 6/12).
