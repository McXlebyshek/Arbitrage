# История и открытый интерес

Пункты 14–16 аудита. Минутная история сохраняет свежие наблюдения ног
сопоставимых по времени и инструменту связок. Открытая карточка и избранные
монеты продлевают наблюдение на две минуты. Страница обновляет подписку каждые
30 секунд. История по рынку, который только открыли, начинает накапливаться с
момента подписки, если ранее он не входил в сопоставимую связку.
Окно 48 часов и прореживание после шести часов сохраняются.

Открытый интерес OKX загружается публичным пакетным запросом SWAP раз в минуту
через фоновый REST-бюджет. Используется значение в USD по идентификатору контракта.
Запись старше двух минут отбрасывается. Тесты проверяют соответствие рынка,
устаревание и нулевой OI. Один публичный запрос вернул 543 инструмента SWAP,
все с заполненным `oiUsd`.
[Документация OKX](https://www.okx.com/docs-v5/en/#public-data-rest-api-get-open-interest)

## Суточное воспроизведение

На закрытой копии исходной SQLite было 570 159 строк, из них 40 320 с OI.
Стенд выбрал фиксированные 120 групп и повторил архивные 60 минут 24 раза
с сохранением разницы временных меток. До и после использованы один SHA-256
архива, 1 651 152 наблюдения и одинаковое окно истории. Избранное и открытые
карточки проверены отдельно тестами.

| Метрика | До | После |
| --- | ---: | ---: |
| Сохранённые точки | 669 419 | 581 281 |
| Размер базы после checkpoint | 58 507 264 байт | 51 523 584 байт |
| Пик базы и WAL | 72 733 656 байт | 63 904 216 байт |
| Запись одной минуты, медиана | 65,775 мс | 59,649 мс |
| Запись одной минуты, p95 | 170,514 мс | 148,368 мс |

База после checkpoint уменьшилась на 11,9%. Replay повторяет один рыночный
час в масштабе суток. Живой суточный замер размера, доступности бирж и покрытия
остаётся в пункте 34. Архив не содержит новых наблюдений OI OKX и используется
для сравнения политики хранения.

Прошли 55 Python-тестов, 17 Node.js-тестов и Playwright.
