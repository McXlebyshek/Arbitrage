# Gate OBU в полном мониторе 0.39.0

## Что проверялось

Изолированный публичный стенд: шесть бирж, 20 активов, четыре соединения Gate по пять контрактов, Binance depth5@500ms в одной группе, штатная проверка книг MEXC. Монитор, локальный UI и три paper-процесса использовали отдельные пути; торговые ключи не требовались. Порог свежести 3 с применяется к времени источника и получения. Для Gate время источника берётся из result.t, а нормализованный BBO помечается ws_depth_verified. REST-глубина для расчёта экономики собирается отдельно.

Группа OBU запрашивает 50 уровней на контракт. Каждый полный WS-снимок заменяет соответствующую книгу. Каждый следующий диапазон обязан начинаться с предыдущего u + 1. Ошибка данных инвалидирует все книги и котировки этого соединения до восстановления. Возобновление публикации происходит по инструментам по мере получения новых полных снимков. Базовый профиль остаётся book_ticker. [Предыдущее одновременное сравнение в двух окнах](GATE_OBU_CHECK.md).

## Воспроизведение

### Результат публичного стенда

Длительность монитора 301,32 с, стенда 306,38 с. После 60 с прогрева сохранено 115 выборок на каждый из 20 контрактов Gate. В SQLite все 2300 котировок имели источник ws_depth_verified и качество ok; каждый контракт, включая TRX и ATOM, дал 115/115. Gate получил 20 полных снимков, без переподключений и кадров, пришедших уже старыми. Для сравнения в предыдущем запуске с тикером TRX дал 61/115, ATOM 60/115. Окна разных запусков не синхронны.

| Биржа | Свежие, прошлый стенд с тикером Gate | Свежие, стенд с OBU | Худшая из 4 полных минут с OBU |
|---|---:|---:|---:|
| Gate | 91,70% | 100% | 100% |
| Binance | 100% | 100% | 100% |
| MEXC | 97,22% | 96,57% | 95,54% |
| Bybit | 99,48% | 99,26% | 99,11% |
| OKX | 99,39% | 99,22% | 98,97% |
| Bitget | 94,57% | 96,78% | 95,69% |

Переподключений не было ни у одной биржи. MEXC зарегистрировал 21 загрузку книги и 7 уже старых кадров. Загрузка CPU после прогрева была 19,25% одного ядра (ранее 17,79%), пиковая RSS 522,7 МиБ (520,4 МиБ), p95 задержки цикла 1,46 мс (1,36 мс), p95 публикации 106,90 мс (102,82 мс). Это нагрузка всего процесса монитора в двух разных рыночных окнах.

Стенд получил 444 ответа API без ошибок. Перезапуск трёх paper-процессов на 150,54 с, переход в архив и блокировка правил после остановки прошли. Market SQLite: 127 819 776 байт, integrity_check=ok. Код монитора 1 из-за неполного покрытия на момент последнего активного снимка. Сохранено 41 событие confirmed, максимум условного сценария 0,365151 USDT при пороге 1 USDT. Виртуальных позиций не открыто. Суточная устойчивость и полный живой цикл остаются открытыми. ### Команда

Из корня проекта запустить команду с новым каталогом результатов и свободным портом.

```powershell
.\.venv\Scripts\python.exe validate_paper_live.py --directory data/gate-obu-next --duration 300 --port 8777 --rules --gate-stream obu
```

Для обычного запуска с новым профилем используется `Start-Monitor.cmd --gate-stream obu`. Поле gate_stream в конфигурации отчёта и статусах соединений Gate показывает активный профиль.
