# Метаданные рынка и компактный снимок

Пункт 19. Браузер запрашивает `/api/markets?compact=1`. Ответ содержит
динамические значения и версию каталога. Статические сведения получаются
из `/api/meta/{version}` один раз на версию. Полный `/api/markets` сохраняет
прежний формат и используется браузером при недоступности метаданных.
Тесты проверяют переиспользование метаданных при смене цены, смену версии
при изменении символа, сохранение предыдущей версии и резервное представление.

Стенд сравнил `d5165cd` и `33de421` на одинаковых 12 000 рынках. HTTP и Chrome
запущены локально. В каждом прогоне 21 замер после пяти прогревов.

| Показатель | До | После |
| --- | ---: | ---: |
| Повторный снимок без сжатия, байт | 3 884 112 | 1 365 164 |
| Повторный снимок gzip, байт | 120 575 | 12 897 |
| Одноразовые метаданные gzip, байт | 0 | 77 102 |
| Первый снимок вместе с метаданными gzip, байт | 120 575 | 89 999 |
| Подготовка публикации, p50 / p95, мс | 11,127 / 11,891 | 24,936 / 28,711 |
| Первый HTTP 200, p50 / p95, мс | 8,171 / 10,096 | 2,715 / 3,461 |
| От публикации до таблицы, p50 / p95, мс | 90,9 / 102,7 | 86,6 / 100,0 |

На этом наборе повторная передача gzip уменьшилась на 89%. Подготовка
публикации стала дороже, поскольку сервер формирует оба представления.
Частота смены каталога и величина выигрыша на живых данных зависят от рынка.

Прошли 57 Python-тестов, 17 Node.js-тестов и Playwright. Chrome запросил
метаданные ровно один раз в сценарии со сменой снимка и HTTP 304.
