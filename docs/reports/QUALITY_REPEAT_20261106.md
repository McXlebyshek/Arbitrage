## Gate TRX

На одном соединении по USDT perpetuals одновременно подписались на futures.book_ticker и futures.obu (50 уровней) для TRX и контрольного XRP. Включён дробный формат. Обе подписки подтверждены. Длительность 120 с. После 20 с прогрева каждую секунду проверяли, был ли кадр в интервале (t−3 с, t] по монотонным часам получения. Максимальная пауза учитывает также начало и конец измерения.

| Инструмент | Кадры ticker / OBU | Макс. пауза ticker / OBU, с | Выборки с недавним кадром ticker / OBU | Только OBU |
|---|---:|---:|---:|---:|
| TRX | 415 / 743 | 22,784 / 2,158 | 71 / 100 из 100 | 29 |
| XRP | 667 / 2537 | 5,095 / 0,378 | 96 / 100 из 100 | 4 |

Когда тикер TRX молчал, тот же транспорт продолжал доставлять глубину TRX. Это сужает поиск причины до поведения отдельных потоков в наблюдаемом окне. Изменения глубины могут относиться к уровням за лучшей ценой. Для допуска OBU в скринер нужен валидированный snapshot с последующими непрерывными диапазонами ID, восстановлением после разрыва и проверкой BBO по времени result.t. Порог 3 с в мониторе применяется по времени источника. [Протокол Gate](https://www.gate.com/docs/developers/futures/ws/en/#order-book-v2-api) · [Результат измерения](GATE_CADENCE_20261106.json).
