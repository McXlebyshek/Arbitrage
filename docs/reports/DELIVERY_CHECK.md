# Проверка доставки 0.21 — 2026-11-05

Реализован отдельный CLI-процесс `arbitrage.delivery` и `Start-Delivery.cmd`.
По умолчанию работает без сетевых запросов; переключение Telegram — только `--send`
с токеном/получателем из переменных процесса. Реальная доставка не включалась.

## Автоматические проверки

13 новых тестов `tests/test_delivery.py`:

- Первый запуск пропускает историю; новая запись доставляется один раз при обычном
  перезапуске. Байты исходной SQLite не изменяются чтением.
- Строгий дополнительный net, фильтры событий и закрытие только объявленного эпизода.
- Истечение TTL и уже потерянные условия исключают отправку opened.
- `retry_after` переживает перезапуск и действует для всех следующих событий
  получателя, даже после истечения TTL первоначального события.
- Лимит попыток и постоянные ошибки завершают обработку события.
- Авария до подтверждения потребляет попытку и оставляет 30с ожидания.
- Смена базы/получателя пропускает историю; отсутствующий источник не создаётся.
- Проверка политики, отдельного файла состояния и ОС-блокировки второго процесса.
- Заглушка HTTPS JSON-запроса: таймаут, запрет редиректов, отсутствие parse_mode.
- Ошибки Telegram/транспорта не раскрывают токен или ответ сервиса; 429/5xx различаются.
- Проверка формата конфигурации получателя и ограничение длины сообщения.

Полный набор: **175 Python-тестов прошли**. Проверки модели графиков: **11 прошли**.
CLI `python -m arbitrage.delivery --test --config delivery.example.json` вернул
`mode=dry_run_no_network`, `status=test_dry_run`. Вызова Telegram не было.

Создание loopback-сокетов asyncio зависало в песочнице Windows; тесты повторены
в разрешённом режиме вне песочницы. Это не заменяло заглушки Telegram реальной сетью.

## Что не подтверждено

Токен, разрешения бота, chat ID, реальная доставка/ограничения конкретного аккаунта
и длительный сетевой прогон ещё не проверены. Настроек получателя в проекте нет.
При потере ответа после принятия сообщения Telegram возможен дубликат с тем же event ID;
exactly-once не заявляется. UI и его таблица в этой версии не изменялись.

Параметры, запуск и ограничения: [DELIVERY.md](../DELIVERY.md).
