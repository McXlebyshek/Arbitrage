# Проверка 2026-11-03

Python 3.14.6, Windows, CCXT 4.5.91. Зависимости зафиксированы в requirements-lock.txt.
Шесть unittest-проверок прошли: фильтрация контрактов, неизвестное время, возраст/цены,
нечисловые значения, единицы объёма и добавление истории SQLite.

Живой запуск публичных REST-запросов вернул по две котировки (BTC, ETH) со всех шести бирж:

| Адаптер | Подходящих активных USDT perpetuals | Результат |
|---|---:|---|
| binanceusdm | 756 | bid/ask через fallback order book |
| bybit | 819 | bid/ask есть, время ticker отсутствует |
| okx | 522 | bid/ask и время ticker есть |
| bitget | 871 | bid/ask и время ticker есть |
| gate | 1070 | bid/ask есть, время ticker отсутствует |
| mexc | 1085 | bid/ask и время ticker есть |

Число контрактов — снимок конкретного запуска, может меняться.
Это проверка доступности и формата ответа, а не непрерывной свежести.
Медленная площадка задерживает публикацию общего REST-снимка, поэтому при публикации
качество всех котировок пересчитывается на общее время. Даже успешно полученные данные
могут уже быть stale. Для рабочего скринера требуется следующий шаг — независимые WS-потоки.

Известные границы: не проверены все контракты в режиме ALL, обрывы сети и длительная работа;
funding, экономика связки и торговая доступность пока не проверяются.

## WebSocket 0.2

17 тестов прошли, включая localhost WebSocket: закрытие сервером, немедленное исключение
старой котировки, повторная подписка и получение нового значения. Остальные проверки
покрывают шесть протоколов, пустые стороны, запрет инкрементов в snapshot-каналах,
ошибки подписок, gzip, сообщения управления и неподтверждённое время MEXC.

Живой прогон 45 секунд с BTC/ETH: все шесть площадок передавали данные.
Binance, Bybit, OKX, Bitget и Gate одновременно имели 2/2 свежие котировки на последних снимках.
MEXC имел 2/2 котировки, но 0 подтверждённо свежих из-за семантики timestamp.
После исправления OKX на порт 443 у всех шести соединений за этот прогон было 0 переподключений.
Gate загружал метаданные дольше остальных, не задерживая их публикацию.
Отдельный начальный прогон выявил notice OKX о выводе порта 8443 из эксплуатации;
обработчик исправлен: уведомление не считается отказом подписки.

Короткий прогон не подтверждает стабильность в течение суток или работу на всём рынке.
Неподтверждённые котировки MEXC остаются известным ограничением, не маскируются успешным статусом.
