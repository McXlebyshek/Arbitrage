# Проверка 2026-11-03

Python 3.14.6, Windows, CCXT 4.5.91. Зависимости зафиксированы в requirements-lock.txt.
Шесть unittest-проверок прошли: фильтрация контрактов, неизвестное время, возраст/цены,
нечисловые значения, единицы объёма и добавление истории SQLite.

Живой запуск публичных REST-запросов вернул по две котировки (BTC, ETH) со всех шести бирж:

| Адаптер | Подходящих активных USDT perpetuals | Результат |
|---|---:|---|
| binanceusdm | 756 | bid/ask через fallback order book |
| bybit | 819 | bid/ask есть, время ticker отсутствует |
| okx | 522 | bid/ask и время ticker есть |
| bitget | 871 | bid/ask и время ticker есть |
| gate | 1070 | bid/ask есть, время ticker отсутствует |
| mexc | 1085 | bid/ask и время ticker есть |

Число контрактов — снимок конкретного запуска, может меняться.
Это проверка доступности и формата ответа, а не непрерывной свежести.
Медленная площадка задерживает публикацию общего REST-снимка, поэтому при публикации
качество всех котировок пересчитывается на общее время. Даже успешно полученные данные
могут уже быть stale. Для рабочего скринера требуется следующий шаг — независимые WS-потоки.

Известные границы: не проверены все контракты в режиме ALL, обрывы сети и длительная работа;
funding, экономика связки и торговая доступность пока не проверяются.

обработчик исправлен: уведомление не считается отказом подписки.

Короткий прогон не подтверждает стабильность в течение суток или работу на всём рынке.

## Охват и стакан MEXC 0.4

47 тестов прошли. Добавлены проверки диапазонов версий MEXC, пропусков, дубликатов,
абсолютных размеров и удаления уровней, границы REST-снимка, блокировки котировки до

Публичный каталог: Binance 756, Bybit 819, OKX 522, Bitget 871, Gate 1070, MEXC 1085
активных линейных USDT swaps на момент проверки. Начальный реестр расширен до
60 явных native id для 10 активов, размер контракта взят из полученных метаданных.

Три живых прогона:

- BTC/ETH, 40 секунд: MEXC синхронизировался; до 12 допустимых котировок и 60 направлений.
- REGISTERED, 45 секунд, group-size=4: 18 соединений, все 60 котировок были допустимы
  на одном из снимков, максимум 256 направлений после фильтра времени. Теоретический максимум — 300.
- ALL, 40 секунд, max-connections=2, mexc-depth-limit=10: выбрано 210 контрактов,
  по два соединения на биржу. Непоместившиеся рынки явно отражены в статусе;
  неизвестные реестру инструменты не получили допуск в скринер.

Код завершения 1 в ограниченном ALL ожидаем из-за omitted_markets. В других прогонах
код также может быть 1 из-за stale на последнем снимке. Проверка не маскирует неполноту.
При штатной остановке текущие связки очищены, история сохранена.

Полный рынок и длительная работа ещё не проверены. Обновление метаданных проверено
детерминированным тестом изменения/удаления контрактов; длительный живой цикл не заявляется.

Финальная проверка установленной версии из G:\Arbitrage: повторно прошли 47 тестов;
35-секундный запуск REGISTERED со стандартными группами дал до 288 направлений и
60 свежих котировок, завершился кодом 0. После завершения все пулы остановлены,
текущие строки скринера очищены. Исходные файлы сверены с проверенной версией по хэшам.
