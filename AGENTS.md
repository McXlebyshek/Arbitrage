# Работа над Arbitrage Monitor

Основная рабочая папка проекта — G:\Arbitrage.
Перед продолжением реализации прочитать docs/ROADMAP.md и учитывать текущие ограничения README.md.

Пользователь просит после каждой завершённой порции работы включать в итоговое сообщение
общий план проекта с отметками выполненного. Обновлять docs/ROADMAP.md и повторять его
нумерованные этапы в кратком виде, используя ✅ выполнено, ◐ частично, ⬜ предстоит.
Отдельно указывать, что изменилось за текущую порцию, результаты проверок и следующий шаг.
Не отмечать частично реализованный или непроверенный этап как полностью выполненный.

Текущий объём — monitor-only через публичные API; реальные торговые операции в MVP не входят.

Для этапа UI использовать присланные пользователем референсы: docs/UI_REFERENCE.md
и изображения в docs/references. Визуальные примеры не являются рыночными данными проекта.
